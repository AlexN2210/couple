 # Break The Routine

 Application React/TypeScript pour créer des surprises anonymes à deux.

 ## Démarrer

 ```bash
 npm install
 npm run dev
 ```

 Les actions, horaires et déclenchements sont conservés dans `localStorage` pour rester utilisables hors-ligne. Copiez `.env.example` vers `.env` et exécutez `supabase/schema.sql` pour préparer le backend Supabase.
